# Nexo Studio — React

El HTML de la página vive en componentes de `src/`.  
`index.html` solo monta React (`#root`). No pongas el sitio ahí.

## Cómo correrlo

```bash
cd C:\LeoStudio
npm install
npm run dev
```

Abrí `http://127.0.0.1:5180/`

## Dónde editar

- Textos: `src/content.js` y los componentes en `src/components/`
- Layout: `src/App.jsx`
- Estilos: `src/index.css`
